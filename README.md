# gta6-meme-x-01 — "Waited 13 Years"

Entry for the make.fun bounty **"Post a GTA 6 meme on X"**: an AI-made meme
about GTA 6, posted on X from a public account, with make.fun in the picture
and in the post's text. An AI judge compares the posts two at a time and the
top 50 share $500.

make.fun is a site where people and their AI agents build things, enter them
in paid competitions (bounties) and earn real money when they win.

## The meme

`meme.png` — a living room at night. Jason and Lucia, exhausted on the couch,
staring at a TV whose GTA VI download bar has been stuck at 97% forever.
Sitting smugly between them: the make.fun ghost, holding its magenta star
coin. It already got paid.

Caption in the picture:

- Top: **WAITED 13 YEARS FOR GTA 6**
- Bottom: **THE DOWNLOAD IS STILL AT 97%**

The joke is the wait itself: thirteen years since GTA V, and now the download
won't finish either — while the ghost, the make.fun mascot, sits there already
paid. The picture was generated by the agent in this session and captioned
with PIL (`../caption.py`); the ghost is drawn from make.fun's own mascot
description (white ghost, thick black outline, sparkle eyes, magenta coin
with a white star).

## The post

The X post (see `POST.json` for its address) carries:

- The meme as its first picture.
- make.fun written out, a link to the bounty page, and a tag of `@makefunai`.
- The entrant's play code `makefun-lemon-jewel-armchair`.
- The pitch, in the meme's own voice: while the download crawls, you and your
  AI agent can already be earning real money in bounties on make.fun.

The exact post text is in `../POSTING.md` (kept out of this repo because the
post is made by hand in a browser, after the meme was built).

## The program

`main.ts` copies `POST.json` from this repository to `/output/POST.json`,
which is all the program has to do. The house reads the post from X itself —
its first picture, then its text — and hands that to the judge. Nothing the
program writes about the post is judged.

Run it locally:

    mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts

`out/POST.json` is then byte for byte this directory's `POST.json`.

## Before you submit

1. Post the meme on X from a public account (not protected), with the picture
   attached and the text from `POSTING.md`, between the bounty's opening and
   its deadline (23 Nov 2026 21:00 WIB).
2. Replace the placeholder in `POST.json` with the post's address:
   `{"url": "https://x.com/<handle>/status/<id>"}`.
3. Run the program as above and check `out/POST.json`.
4. From the kit's directory, run the pre-submit checks, then submit per the
   kit's `RULES.txt` (Enter).

Keep the post up and the account public until the results are out. Each
submission may name a new post; the last submission before the deadline is
the final entry.
